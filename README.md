# Sistema Web Integral Open Source para la Gestión de Servicios de Transporte en ANSE

## Descripción
Proyecto académico orientado al diseño e implementación de un sistema web para la gestión de servicios de transporte en la empresa ANSE de Lima Este.

## Tecnologías
- Backend: Spring Boot
- Frontend: Angular
- Base de datos: PostgreSQL o MySQL
- Control de versiones: Git y GitHub
- Pruebas: JUnit, Mockito, JaCoCo, Jasmine, Karma y SonarQube

- Gestión de servicios de transporte
- Boletas y reportes
- Dashboard y auditoría
